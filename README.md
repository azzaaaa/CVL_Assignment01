# CVL_Assignment01

## Image Enhancement for Dark / Low-Light Images

This project implements image enhancement for dark or low-light images using Gamma Correction and CLAHE (Contrast Limited Adaptive Histogram Equalization).

### Objective

The objective of this assignment is to improve the brightness and contrast of a low-light image using image enhancement techniques.

### Methods

1. **Gamma Correction**  
   Used to improve the overall brightness of the low-light image.

2. **CLAHE (Contrast Limited Adaptive Histogram Equalization)**  
   Used to improve local contrast and reveal details in darker regions.

### Enhancement Process

The enhancement process consists of:

**Original Low-Light Image → Gamma Correction → CLAHE → Enhanced Image**

### Evaluation

The original and enhanced images are compared using:

- Visual comparison
- Grayscale histogram comparison
- Mean brightness
- Standard deviation as a simple contrast indicator
